# 🇨🇦 Canadian City AI Chatbots (Zero-Cost Multi-Tenant Monorepo)

An ultra-performant, highly-monetized, multi-tenant AI chatbot network and automated civic scraper serving **10 Canadian metropolitan domains** from a unified Next.js 15 App Router codebase. Powered by Upstash Vector, Groq, Google Gemini, and advanced affiliate routing logic.

## 🌟 Key Features & Systems

### 1. Multi-Tenant Domain Routing
A single Next.js deployment seamlessly serves 10 distinct domains (e.g., `chatyyc.com`, `chatyyz.com`, `chatyvr.com`). Using Next.js Middleware, traffic is intercepted, analyzed, and rewritten to the appropriate city context on-the-fly, instantly applying regional themes, colors, and initial AI contexts.

### 2. Multi-Tier AI Inference Engine & Fallbacks
We utilize a highly resilient, cost-optimized, ultra-low latency AI pipeline:
- **Tier 1 (Instant):** Upstash LRU Semantic Cache (Zero token cost, ~15ms).
- **Tier 2 (Primary):** Groq Llama-3.3-70B-Versatile (High reasoning, ~300ms).
- **Tier 3 (Speed/Failover):** Groq Llama-3.1-8B-Instant (Fallback speed tier).
- **Tier 4 (Ultimate Fallback):** Google Gemini 1.5 Flash / Pro (High context window).

### 3. Integrated Affiliate Monetization System
All outbound links generated by the AI (e.g., concert tickets, dinner reservations, hotel bookings) are automatically intercepted and injected with affiliate tracking parameters. 
- Supports **CJ Affiliate**, **Impact Network**, **Rakuten (OpenTable)**, **Viator**, **GetYourGuide**, and **Ticketmaster**.
- Seamless Markdown rewriting via custom `remark` plugins.
- Built-in UI Display Ads (`<DisplayAd />`) dynamically served within the regional radar.

### 4. Executive Telemetry & Admin Portal (`/admin`)
A secure, real-time analytics dashboard designed for project governance.
- **Access via:** `https://yourdomain.com/admin` (Requires `ADMIN_API_TOKEN`).
- Tracks live token consumption, estimated infrastructure cost savings, category distribution of queries, and affiliate link click conversions.
- Manages Citizen Bug/Feedback Reports via a robust status tracking grid.

### 5. Automated Civic Scraper (GitHub Actions)
A headless cron-job scraper that targets municipal websites, event boards, and 311 alert systems, automatically chunking and upserting localized semantic context into Upstash Vector for RAG (Retrieval-Augmented Generation).

```
│       │   │   ├── chat/          # Glassmorphism chat & Markdown renderer
│       │   │   ├── radar/         # Real-time local news & event UI
│       │   │   └── layout/        # Dynamic city headers & layouts
│       │   └── lib/
│       │       ├── affiliate-config.ts # Network monetization rules
│       │       ├── tenants.ts     # Domain-to-city definitions
│       │       └── telemetry.ts   # In-memory fast analytics engine

│       └── next.config.ts         # Hardened security headers
└── turbo.json                     # Turborepo build pipeline
```

## ⚡ Quick Start (Local Development)

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Create `.env.local` inside `apps/web/`:
```bash
# apps/web/.env.local

# Upstash Vector RAG
UPSTASH_VECTOR_REST_URL=https://your-index-url.upstash.io
UPSTASH_VECTOR_REST_TOKEN=your-token

# AI Providers
GROQ_API_KEY=gsk_your_groq_api_key
GOOGLE_GENERATIVE_AI_API_KEY=your_gemini_api_key

# Affiliate Monetization APIs
NEXT_PUBLIC_CJ_API_KEY=your_cj_api_key
# Other network parameters managed internally

# Secure Admin Portal
ADMIN_API_TOKEN=super_secret_secure_password_for_admin_portal
```

### 3. Start Next.js Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
Test different cities locally by appending `?city=yvr` or navigating to `http://localhost:3000/yyc`.

## 🛡️ Security Posture
- **Strict Content Security Policies:** Defined in `next.config.ts`.
- **API Rate Limiting:** Request throttling on feedback and admin paths.
- **Token Budgeting:** Truncated message context windows to prevent LLM bankruptcy.
- **Model Guardrails:** Injection defenses mapped into primary Llama 3.3 prompts.
